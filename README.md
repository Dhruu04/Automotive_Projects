## Portfolio Engineering Taxonomy (8 Operational Sectors)

The 50 systems are structured across 8 operational and engineering disciplines:

1. **Electrification, Battery Management & Charging (10 Systems):** State of health tracking, 4C fast-charge lithium plating defense, submerged dielectric cooling, wireless BMS RF latency, and bi-directional V2G grid balancing (*CATL, BYD, Volkswagen, GM, Lucid, NIO, EV Powertrain*).
2. **Autonomous Driving & Active ADAS Perception (6 Systems):** Multi-sensor radar/camera Kalman fusion, Level 3 takeover gaze monitoring, shadow-mode edge case fleet mining, and pedestrian trajectory safety (*Mercedes-Benz, Tesla, Volvo Cars, Autonomous Mobility*).
3. **Motorsport Dynamics & Hypercar Engineering (8 Systems):** Hybrid MGU-K energy release, active aero downforce balance, pre-chamber twin-spark knock control, carbon-ceramic thermal wear, and MotoGP 6-axis IMU slide control (*Ferrari, Porsche, Lamborghini, Maserati, Brembo, Pirelli, Ducati, Rimac, Koenigsegg, McLaren*).
4. **Commercial Fleet Logistics & Telemetry (8 Systems):** Predictive engine wear diagnostics, eco-driving safety profiling, assembly logistics route solvers, heavy truck aerodynamic platooning, and fuel load regression (*Scania, Freight Logistics, Commercial Telemetry*).
5. **Smart Manufacturing & Factory Quality Vision (6 Systems):** Automated camera surface inspection, stamping press vibration Kaizen, ultrasonic C-scan non-destructive testing for composite tubs (*Toyota, Pagani, Manufacturing Quality*).
6. **Powertrain, Hybrids & Alternative Energy (7 Systems):** Dual-motor e:HEV torque blending, Euro 7 real driving emissions, 700-bar hydrogen fuel cell hydration, and E100 bio-ethanol cold-start AI (*Honda, Stellantis, Iveco, Stellantis South America*).
7. **Chassis Dynamics & NVH Acoustics (5 Systems):** Hydraulic brake modulator wear, carbon driveshaft resonance damping, camera pothole preview pre-damping, and smart tire hydroplaning detection (*Bosch, Continental, Alfa Romeo, Genesis, ZF*).
8. **E/E Architecture & Commercial Operations (2 Systems):** Centralized zonal vehicle Ethernet gateway congestion, used vehicle market valuation, and dealership warranty claim fraud auditing (*Aptiv/Rivian, Automotive Remarketing, Aftersales Operations*).

## Getting Started & Local Execution

### 1. Prerequisites
- Python 3.10 or higher
- Modern web browser (Chrome, Edge, Firefox, Safari)

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/Dhruu04/Automotive_Projects.git
cd Automotive_Projects

# Install required dependencies
pip install -r requirements.txt
```

### 3. Rebuilding the Complete Portfolio
To rebuild all 50 interactive reports, regenerate all datasets, update all project README files, and compile the master executive dashboard in a single execution:
```bash
python build_all_portfolio.py
```

### 4. Running a Single Project Standalone
To execute and inspect a single sub-system independently without building the entire portfolio:
```bash
cd 31_ferrari_mguk_hybrid_deployment
python generate_report.py
```

### 5. Accessing the Dashboard
Open `index.html` in any web browser to explore the interactive master management hub.
